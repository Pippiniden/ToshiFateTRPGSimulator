# 聖杯戦争TRPG バランス試験場

TRPGの戦闘バランスを大量試行で検証する、ブラウザだけで動く静的Webツールです。
要件定義書 v0.1 の MVP 範囲（キャラ・スキル・状態・ダイス／判定・イベント・AI・大量シミュレーション・統計）に加え、
比較（A案/B案）・パラメータスイープ・1対1総当たりを実装しています。

## GitHub Pages で公開する

1. このフォルダの中身（`index.html` / `css/` / `js/` / `.nojekyll`）をリポジトリのルートに置いて push
2. GitHub のリポジトリ → **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `(root)` に設定
3. 数十秒後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

ビルド手順や外部ライブラリは不要です（フォントのみ Google Fonts から読み込み）。

## ローカルで試す

Web Worker を使うため、`index.html` を直接ダブルクリックするより簡易サーバー経由がおすすめです。

```
python3 -m http.server 8000
# → http://localhost:8000/
```

（直接開いた場合も動きますが、並列実行が使えずメインスレッドで計算します）

## 用語

ターン＝移動・遭遇・交戦の全フェイズの一巡り、フェイズ＝移動・遭遇・交戦それぞれ、巡＝交戦フェイズ内の手番の一巡り。
シミュレーターは各ターンの交戦フェイズを戦わせ、決着しなければ次のターンの交戦フェイズへ進みます（間の移動フェイズの効果だけ処理）。

## テスト

```
node tests/engagement-end.test.js
```

全テストケースとサーヴァント同士の全1対1で戦闘を回し、交戦フェイズの境目ごとに、交戦フェイズ限りの状態・召喚体・変容・回数制限・EX振り直し・マスター喪失の処理が正しいかを検査します。

## 主な機能

- **テスト実行**：陣営・前衛/後衛・要（倒れたら敗北）を組んで数千〜数十万回試行。勝率（95%信頼区間）、巡数の分布、キャラ別の死亡率・与被ダメージ・残HP、スキル使用率、代表試行の詳細ログ
- **キャラクター編集**：ランク表示と内部値の分離、英雄点の自動計算、任意リソース、スキル／宝具をブロック（タイミング × 攻撃種別 × 条件 × 効果）で定義
- **キャラシート取り込み**：`【クラス】【真名】【筋力】…` 形式のテキストからステータスとスキル名・コスト・効果文を一括登録
- **マスター**：メンバーの ⚙ でサーヴァントにマスターを指定。マスタースキルは「自分のサーヴァント」に効き、マスター脱落時はサーヴァントがマスターのHP分のダメージを受けて交戦終了時に消滅（単独行動なら次の交戦まで）。マスター22体（ドローン）を収録
- **援護**：1回の攻撃に複数の味方の援護を重ねられる。AIは補正値ペナルティを考慮して人数を決める（王の軍勢が神威の車輪やイスカンダルの攻撃を底上げする等）
- **英雄点と初期令呪**：令呪コスト＝⌈(英雄点−予算)÷5⌉＋作成時に失う令呪、予算＝基本30＋「英雄点を得る」スキル（サーヴァント＋契約マスター）。収録26騎のシート記載と一致することを検算済み。組むマスターによって初期令呪が変わる
- **令呪**：各PLは3画−サーヴァントの令呪コストで開始（マスター未配置ならサーヴァント本人が保持）。戦闘用の7効果をAIが状況判断で使用（致命傷時の振り直し+3、HP30回復、2画で宝具回数回復、マスターを庇う対象変更、マスターの判定+5など）。陣営ごとに「なし／通常／積極的／使わない」を選択可。スイープで開始時の令呪画数も動かせる
- **召喚**：効果「召喚」で乗騎・使い魔を戦闘中に呼び出し（体数は式可、交戦終了で消える／召喚者と運命を共にする）。ペガサス・神威の車輪はライダーの最初の手番開始時に召喚。王の軍勢（3D6体、総数が半分以下で陣地ごと消滅）、子機、魔神柱にも使用
- **陣地**：陣地作成（陣営フラグ「陣地」）、陣地扱いの状態（無限の剣製・パンドラボックス）、固有結界の召喚体（王の軍勢）は、相手の陣地破壊で消滅
- **特殊な宝具・スキル**：令呪を消費して発動する宝具（エヌマ・エリシュ）、HPが0になった時の復活（十二の試練）、交戦ごとのステータス振り直し（変容）。宝具は1回の判定につき1つまで
- **消耗（開始時の状態）**：メンバーごとに開始HP（値・割合・ランダム範囲）、宝具・令呪などの残り、掛かっている状態、使用済みスキルを設定。スイープで「開始HP%」も動かせる
- **ボス例**：ビーストⅠ（魔神王ゲーティア）、ビーストⅢ／R（殺生院キアラ）。FGOの設定を元にした試作シートで、PC4騎で勝率約40%に調整
- **状態**：バフ／デバフ（持続・回数・デバフ扱い）をスキルと同じブロックで定義
- **ルール**：ステータス項目、ランク表、ダイス面数と上下限、補正値ペナルティ、最大HP式、攻撃種別
- **比較・スイープ・総当たり**：保存した結果の比較、値を範囲で変えた勝率曲線、1対1の相性表。総当たりは「援護・乗騎・召喚・宝具・令呪・陣地・同盟」の有り無しをチェックボックスで切り替えて比べられます（陣地ありでは、陣地作成を持つキャラが自陣で戦います）

同じシードなら同じ結果が再現されます（並列実行しても同一）。設定はブラウザに自動保存されます。

### 共有（書き出し・読み込み）
- **キャラクター**：キャラクター画面の「書き出し」（1体）／「書き出し…」（複数選択）。付与する状態・召喚先の乗騎も同梱
- **テストケース**：テスト実行画面の「書き出し」。使っているキャラクター・状態も同梱
- **全データ**：画面右上の「書き出し」
- どれも「テキストでコピー」でチャットに貼れる。受け取り側は「読み込み…」でファイル選択かテキスト貼り付け
- 読み込みは今のデータへの追加。同名があれば「既存を使う／別名で追加／上書き」を選択（内容が同じものは既存を使うのが既定）

## 近似・未対応

交戦フェイズを中心に再現しています。移動・遭遇フェイズ、移動・RP用の令呪、同盟・裏切り、遠距離攻撃フェイズ、魂喰い、再契約、前衛／後衛の入れ替え行動は対象外です。
陣地は陣営フラグで近似できます。各スキルの近似内容はメモ欄に記載しています。
